# The Narrative Pivot

Tools, skills, and workflows for The Narrative Pivot - a Substack newsletter targeting B2B SaaS founders and business leaders who need help with messaging, positioning, and internal alignment.

## What's Inside

### Skills

**Content Workflow (`skills/core/`)**: Active workflow stages for producing original, voice-consistent Substack posts
- Voice rules and editorial guidelines
- Outline and line-editing processes
- Relevance checking and suggestion workflows

**Research Workflows (`skills/research/`)**: Pre-writing research on messaging, positioning, and sales enablement

**Homepage Review (`skills/homepage-review/`)**: B2B SaaS homepage evaluation framework
- Analyzes homepages for specificity, "So What?" moments, and pain-point-driven messaging
- Based on April Dunford's positioning framework adapted for homepage evaluation
- Generates diagnostic reports with copy rewrites and recommendations

### Automation

Automation scripts for content workflow and Notion integration

## Homepage Review Skill

The newest addition - a framework for evaluating B2B SaaS homepages based on:
- Hero section specificity (who it's for, what it is)
- "So What?" moment using Dunford's 5 positioning components
- Pain-point-driven features vs. generic jargon
- Overall tier: Bare Minimum → Good → Better → Excellent

See `skills/homepage-review/README.md` for details.
