# Notion Database Schema for The Narrative Pivot Idea Pipeline

This document shows you how to set up your Notion database for storing and tracking content ideas generated by the research workflows.

---

## Database Setup

1. Create a new **database** in Notion (not a page)
2. Name it: **Content Idea Pipeline**
3. Add the following properties:

### Properties (Fields)

| Property Name | Type | Options/Description |
|--------------|------|---------------------|
| **Working Title** | Title | The punchy, declarative headline from Gemini |
| **Topic** | Select | Options: `Messaging Consistency`, `Positioning in the AI Era`, `Sales Enablement` |
| **Core Thesis** | Text | The one-sentence inversion or reframe |
| **Symptom Reader Recognizes** | Text | What they'd Google or complain about |
| **Competitive Gap** | Text | Why this post exists if PMM creators already write about this |
| **Potential Hook** | Text | One sentence that could open the piece |
| **What Reader Walks Away Able to Do** | Text | One specific, immediate action |
| **Score** | Number | Total score from Gemini ranking (max 15) |
| **Status** | Select | Options: `Research Complete`, `Outlining`, `Drafting`, `Editing`, `Published`, `Archived` |
| **Date Added** | Date | When the idea was added to Notion |
| **Research Source** | URL | Link to Perplexity thread (if available) |
| **Supporting Evidence** | Text (long) | Quotes, examples, or patterns from Perplexity research |
| **Notes** | Text (long) | Your brain dump, lived experience, or observations to anchor the post |

---

## Views to Create

### 1. **By Topic** (Board View)
- Group by: **Topic**
- Sort by: **Score** (descending)
- Filter: **Status** is `Research Complete`

Use this view to see all validated ideas organized by topic.

---

### 2. **Ready to Write** (Table View)
- Filter: **Status** is `Research Complete`
- Sort by: **Score** (descending), then **Date Added** (newest first)

Use this view to pick your next post to develop.

---

### 3. **In Progress** (Table View)
- Filter: **Status** is `Outlining`, `Drafting`, or `Editing`
- Sort by: **Date Added** (oldest first)

Use this view to see what you're currently working on.

---

### 4. **Published Archive** (Gallery View)
- Filter: **Status** is `Published`
- Sort by: **Date Added** (newest first)

Use this view to see your published posts and avoid repeating topics.

---

## Workflow: Adding Ideas from Gemini

After running Gemini analysis, add each idea to Notion:

1. **Create a new entry** in the Content Idea Pipeline database
2. **Fill in fields** from Gemini output:
   - Working Title
   - Topic (select the research workflow you ran)
   - Core Thesis
   - Symptom Reader Recognizes
   - Competitive Gap
   - Potential Hook
   - What Reader Walks Away Able to Do
   - Supporting Evidence
   - Score (from Gemini ranking)
3. **Set status** to `Research Complete`
4. **Add date** (today)
5. **Paste Perplexity link** in Research Source (if available)

---

## Workflow: Selecting an Idea to Develop

1. Open the **Ready to Write** view
2. Sort by **Score** to see highest-scoring ideas first
3. Review **Competitive Gap** and **Supporting Evidence** to pick one
4. Change **Status** to `Outlining`
5. Copy the idea details and paste into Claude to start Stage 3

---

## Workflow: Tracking Progress

As you move through Claude stages, update the Status:

- **Research Complete** → idea validated, not yet started
- **Outlining** → Stage 3 in progress
- **Drafting** → Stages 4-6 in progress (editorial, line edit, suggestions)
- **Editing** → Stages 7-8 in progress (relevance check, final pass)
- **Published** → post is live on Substack
- **Archived** → idea no longer relevant or decided not to pursue

---

## Optional: Weekly Research Reminder

Set up a **Notion reminder** or calendar event every Monday to run your research workflows:

1. Run Perplexity prompt for one topic
2. Feed results into Gemini prompt
3. Add 7-10 new ideas to Notion
4. Review and pick one to develop this week

This keeps your pipeline fresh with validated, differentiated ideas.
